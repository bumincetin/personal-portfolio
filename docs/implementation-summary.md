# Implementation summary

The practice is a readable library with optional interactive shelf and book
views. Detailed test evidence and measurement limits are in
[library-audit.md](library-audit.md).

## Routes and content

| Route | Current behavior |
| --- | --- |
| `/[locale]` | Server-rendered introduction and seven-entry catalogue; explicit 3D entry |
| `/[locale]/front-matter` | Approach article with an optional book view |
| `/[locale]/volumes/[slug]` | Service, research, or synthetic demonstration; shared article/book content |
| `/[locale]/chapters` | About / CV, five career chapters, existing portrait and printable record |
| `/[locale]/contact` | Verified direct links, message composer, optional guided questions and sculpture |
| `/api/contact` | Retained endpoint; the public composer does not call it |

All routes remain available in English, Turkish and Italian. Canonical URLs,
hreflang, sitemap and historical redirects remain. `/about` redirects to
`/chapters`, not to contact. Ordinary navigation labels describe the task;
literary volume titles remain part of the collection identity.

## Presentation and lifecycle

Espresso, bone and muted brass remain the palette. Instrument Serif handles
display type, Newsreader prose and Inter interface text. Primary actions use
light fills; secondary actions use borders and tertiary links use underlines.
The navbar uses the transparent `logo-mark.webp` generated by
`scripts/make-logo-mark.mjs`; it does not invert or screen-blend the original.

The catalogue scrolls normally and works without JavaScript. `ShelfLauncher`
opens a native modal and only then imports the shelf. Leaving, failed loading,
context loss, navigation and unmount release the scroll lock. The engine scopes
DOM queries and keys, includes every eligible control in its inner focus trap,
checks cancellation after initialization awaits and disposes partial work.
Its decorative animation settles after 1800 ms; transitions and interaction
remain available, and the pause control stops decorative motion.

Articles are the initial document, including on mobile and reduced motion.
Book preference is remembered in memory on desktop. The DOM book moves the
original leaves and returns them to their section before teardown. Curved turns
retain the 18-strip geometry on mobile and desktop; the automatic introductory
riffle was removed. Inert, hidden decorative copies have no duplicate IDs and
omit the optimizer widget. The optimizer mounts once, only on activation.
Before printing, the reader restores the complete article. The CV keeps its
existing print treatment.

Contact state stays in page memory. Simple and guided presentations share all
answers and any edited message; an explicit action replaces a manually edited
draft with current answers. Only the message is required. Destinations open a
draft, and the visitor sends it in their app. Copy is available when app links
fail or become too long. No provider, scheduling service or analytics sink was
enabled.

## Maintained source and generation

- Shelf: `scripts/port-shelf-engine.mjs` verifies the frozen repository port and
  applies `scripts/shelf-adapter.mjs`. Run it after adapter edits and verify with
  `npm run test:generated`. The original extraction generator/canonical HTML was
  absent; the precise distinction and both hashes are in the audit.
- Shelf styles: authored generated `shelf.css` is unchanged; application changes
  belong in `shelf-overrides.css` and the independent HTML catalogue stylesheet.
- Reader: `engine.js` is the maintained DOM adapter; `sketchbook.css` is generated
  by `scripts/port-sketchbook-css.mjs` from the original hash-checked HTML.
  `article.css` and `sketchbook-overrides.css` own application layout.
- Vendor originals, texture bytes and notices remain. `.gitattributes` protects
  integrity-checked text from Windows newline conversion.

Builds remain Next.js App Router through Cloudflare/OpenNext. The audit uses
separate `NEXT_DIST_DIR` directories for before/after production servers so
rebuilding cannot invalidate a browser's current chunks. Runtime performance
claims must refer to actual request and Lighthouse reports, not dependency
installation size or historical build output.

## Verification boundaries

`npm run verify` covers lint, types, locale structure, static contrast, unit
tests and a production Next build. Browser scripts explicitly activate the
optional experiences where they test them. New library regressions cover the
default HTML path, no-3D loading, focus, cancellation, localized failures,
view switching, print and browser-engine behavior. Existing source/evidence,
link, redirect, touch, geometry and accessibility assertions remain.

Zero axe violations and emulated touch tests are not WCAG certification or
physical-device testing. Native-speaker review, screen-reader sessions,
real-phone checks and real-user Core Web Vitals remain separately reportable
owner work. No deployment or real-message test occurred.
